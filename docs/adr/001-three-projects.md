# ADR 001：三個專案、兩個後端依特性分工

## 背景

作品集要同時展示前端（Vue）、C#／ASP.NET 與 Go 三種能力，並對上目標職缺的要求。

## 考慮過的選項

1. Nuxt 一個專案包前後端（Nuxt server routes）
2. Nuxt + Go 兩個專案
3. Nuxt + ASP.NET Core + Go 三個專案

## 決定

選 3。web 只放頁面；api（C#）負責會員、CRUD、設定、報表、AI 與對外整合；core（Go）負責即時、高併發與原子操作。

## 取捨

- 優點：職責清楚、三種技術各有明確展示點、面試好說明
- 缺點：多一個服務要部署；跨服務登入要靠共用 JWT 密鑰；schema 要在兩個後端之間同步（見 ADR 002）
